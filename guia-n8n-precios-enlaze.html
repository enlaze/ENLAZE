Guía de Sincronización de Precios

Configura n8n para rastrear precios del mercado español automáticamente y enviarlos a ENLAZE

1. Configuración Inicial

1.1 Variable de entorno necesaria

Añade esta variable en tu .env de ENLAZE (Vercel):

# Genera una clave segura:
# openssl rand -hex 32
SYNC_API_KEY=tu_clave_secreta_aqui_de_64_caracteres

Esta misma clave la configurarás en n8n como credencial para autenticar las llamadas.

1.2 Configuración en n8n

  1. Crea una credencial "Header Auth" en n8n:
    Name: ENLAZE Sync API
    Header Name: Authorization
    Header Value: Bearer TU_SYNC_API_KEY
  2. URL del endpoint:
    https://tu-dominio.vercel.app/api/pb/ingest
    Método: POST
    Content-Type: application/json
  3. Formato del body que n8n debe enviar: 
    {
  "provider_name": "Leroy Merlin",
  "sector": "construccion",
  "source_url": "https://www.leroymerlin.es/...",
  "products": [
    {
      "name": "Cemento Portland 25kg",
      "price": 4.95,
      "unit": "saco",
      "category": "material",
      "subcategory": "cementos",
      "brand": "Lafarge",
      "sku": "LM-12345"
    }
  ]
}
  4. Programa el Schedule Trigger de cada workflow para ejecutarse cada día a las 06:00 AM (o la hora que prefieras).

2. Estructura del Workflow n8n (Plantilla)

Cada workflow de scraping sigue esta estructura de 5 nodos:

  1. Schedule Trigger — Cron: 0 6 * * * (cada día a las 6:00)
    O puedes usar "Every day at 06:00"
  2. HTTP Request — GET a la URL del proveedor
    Configuración: Response Format = Text, Follow Redirects = sí
    Añadir Headers: User-Agent: Mozilla/5.0 ...
  3. HTML Extract — Extrae los datos con selectores CSS
    Extraction Values: name, price, unit, brand, sku (selectores específicos por proveedor, ver sección 3)
  4. Code (JavaScript) — Transforma y limpia los datos: 
    // Nodo "Code" en n8n — transformar datos extraídos
const products = [];

for (const item of $input.all()) {
  const rawPrice = item.json.price || "";
  // Limpiar precio: "4,95 €" → 4.95
  const price = parseFloat(
    rawPrice.replace(/[^\d,\.]/g, "")
           .replace(",", ".")
  );

  if (!item.json.name || isNaN(price)) continue;

  products.push({
    name: item.json.name.trim(),
    price: price,
    unit: item.json.unit || "ud",
    category: item.json.category || "material",
    subcategory: item.json.subcategory || "",
    brand: item.json.brand || "",
    sku: item.json.sku || "",
  });
}

return [{
  json: {
    provider_name: "NOMBRE_PROVEEDOR",
    sector: "SECTOR",
    source_url: $input.first().json.url || "",
    products: products
  }
}];
  5. HTTP Request — POST a ENLAZE
    URL: https://tu-dominio.vercel.app/api/pb/ingest
    Auth: Credencial "ENLAZE Sync API"
    Body: {{ $json }}

4. Ejemplo Completo: Workflow "Leroy Merlin → Cementos"

Te muestro paso a paso un workflow real para scrapear una categoría de Leroy Merlin:

Nodo 1: Schedule Trigger

Trigger: Cron
Expression: 0 6 * * *
// Cada día a las 06:00

Nodo 2: HTTP Request

Method: GET
URL: https://www.leroymerlin.es/productos/materiales-construccion/cementos-y-morteros/
Headers:
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
  Accept: text/html
Response Format: Text

Nodo 3: HTML Extract

Source Data: Body
Extraction Values:
  - Key: name     | CSS Selector: .product-card .product-title | Return: text
  - Key: price    | CSS Selector: .product-card .price-amount  | Return: text
  - Key: unit     | CSS Selector: .product-card .price-unit    | Return: text
  - Key: brand    | CSS Selector: .product-card .product-brand | Return: text
  - Key: sku      | CSS Selector: .product-card [data-ref]     | Return: attr (data-ref)
Return Array: Yes

Nodo 4: Code (JavaScript)

const products = [];

for (const item of $input.all()) {
  const rawPrice = item.json.price || "";
  const price = parseFloat(
    rawPrice.replace(/[^\d,\.]/g, "").replace(",", ".")
  );

  if (!item.json.name || isNaN(price) || price <= 0) continue;

  products.push({
    name: item.json.name.trim(),
    price,
    unit: (item.json.unit || "ud").trim(),
    category: "material",
    subcategory: "cementos",
    brand: (item.json.brand || "").trim(),
    sku: (item.json.sku || "").trim(),
  });
}

return [{
  json: {
    provider_name: "Leroy Merlin",
    sector: "construccion",
    source_url: "https://www.leroymerlin.es/productos/materiales-construccion/cementos-y-morteros/",
    products
  }
}];

Nodo 5: HTTP Request → ENLAZE

Method: POST
URL: https://tu-dominio.vercel.app/api/pb/ingest
Authentication: Header Auth → "ENLAZE Sync API"
Content Type: JSON
Body: Expression → {{ $json }}

// La respuesta será algo como:
{
  "ok": true,
  "inserted": 12,
  "updated": 3,
  "unchanged": 5,
  "errors": 0,
  "total": 20
}

6. Monitorización y Alertas

El endpoint /api/pb/ingest registra automáticamente cada sincronización en la tabla price_sync_logs y cada precio en pb_price_observations. Puedes ver el estado en tu dashboard de ENLAZE en la pestaña "Informe" del rastreador de precios.

Crear un workflow de alerta en n8n:

Puedes crear un workflow que revise price_sync_logs cada día y te envíe un email/Telegram si hubo errores:

// Nodo Code para verificar última sincronización
const response = await $http.get(
  "https://tu-dominio.vercel.app/api/pb/sync/status",
  { headers: { Authorization: "Bearer TU_KEY" } }
);

const { lastRun, staleProducts } = response.data;

if (staleProducts > 50 || !lastRun) {
  return [{ json: { alert: true, message: `${staleProducts} productos sin actualizar` } }];
}
return [];

7. Consejos y Mejores Prácticas

TemaRecomendación
Rate limitingNo hagas más de 1 petición por segundo a cada web. Usa el nodo "Wait" de n8n entre páginas.
User-AgentUsa un User-Agent de navegador real para evitar bloqueos.
PaginaciónMuchas webs paginan los productos. Usa un Loop en n8n: página 1, 2, 3... hasta que no haya más.
ErroresConfigura reintentos (Retry on Fail = 2) en los nodos HTTP Request.
Webs con JSPara webs que renderizan con JavaScript (React, Angular), necesitas un nodo Puppeteer/Playwright o un servicio como ScrapingBee.
Límite del endpointMáximo 500 productos por llamada a /api/pb/ingest. Si tienes más, divide en lotes.
Sectores válidosconstruccion, comercio_local, estetica, hosteleria, automocion, educacion
PreciosEnvía siempre precios SIN IVA y en EUR. El campo price es numérico (no string).
Aviso legal: El scraping de precios de webs públicas para uso privado/interno generalmente está permitido en España (datos públicos), pero respeta siempre los robots.txt de cada web y no sobrecargues sus servidores. Si un proveedor ofrece una API oficial, úsala en vez de scraping.
